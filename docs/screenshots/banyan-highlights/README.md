# Banyan website highlights

15 screenshots captured from [Banyan’s live demo](https://banyan.aaravreddy.org) on September 20, 2026. The set covers donor investigation, funding plans, nonprofit learning, evidence, reports, and permissions.

All images are original browser captures at 1600 CSS pixels wide. Short screens and long lists use a 1600 × 1100 viewport; detail pages use full-page captures. Screenshots 09 and 13 are scrolled to the highlighted section. Demo labels, read-only notices, and draft status remain visible wherever the selected view displays them. Organizations and program evidence are fictional.

Existing records were browsed without saving plans, uploading files, changing permissions, or approving records. No application code was edited and no application tests were run.
